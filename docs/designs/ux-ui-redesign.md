## Vision

### 10x Check
Make GearFlow the best-looking rental management software in the industry. Not just "not AI-generated" — genuinely beautiful. Linear meets Stripe Dashboard meets Notion. The kind of UI where an AV rental company shows it to a competitor and they ask "what is that?" Confident, fast, calm, delightful.

### Platonic Ideal
If the best designer built GearFlow, the user would feel:
- **Confident** — Every pixel communicates competence
- **Fast** — Anything reachable in 2 clicks max
- **Calm** — No visual noise, information appears when needed
- **Delighted** — Small moments of "oh nice" throughout
