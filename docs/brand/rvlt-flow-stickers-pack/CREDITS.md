# Credits and provenance

## Adapted icon geometry

Ten illustrations adapt Phosphor Icons by Helena Zhang and Tobias Fried: road case, microphone, monitor, production van, wrench, calendar, AAA pass, clipboard, speaker and ticket stub. Their SVG metadata records the original source and the changes. The MIT notice is included at `assets/licenses/phosphor-MIT.txt`. The per-design mapping is in `manifest.json`.

Source family: https://github.com/phosphor-icons/core

## Lettering

Wordmark layouts use Archivo and Baloo 2, converted to vector paths. No runtime font files are required. The source font notices are preserved at `assets/licenses/Archivo-OFL.txt` and `assets/licenses/Baloo2-OFL.txt`.

- Archivo: https://github.com/google/fonts/tree/main/ofl/archivo
- Baloo 2: https://github.com/google/fonts/tree/main/ofl/baloo2

## Custom layouts and references

The companion drawings, sticker treatment and word-patch compositions were developed for RVLT Flow. This pack does not assign a new blanket open-source licence to the complete RVLT artwork collection. The supplied third-party licences apply to their respective source material.

The illustrated guide documents the RVLT design-language references, pelican anatomy research, Stay Home Club patch inspiration and stage-light/mixer references. Those external source photographs and reference artworks are not included as production assets.

Brand references:

- https://rvlt-labs.github.io/rvlt-designlanguage/
- https://rvlt-labs.github.io/rvlt-designlanguage/preview
- https://flow.rvlt.app/login?callbackUrl=%2F

The exact source repository commit and SHA-256 hashes appear in `manifest.json`. The original design guide is included unchanged, with a Markdown rendition for agent use. Keep the source notices with distributed asset files and retain this pack as a reference copy.
