## Overview

Complete rewrite of the project, finance, quoting, and crew modules. Projects become the single source of truth for a job — from enquiry through to wrap. Finance calculations rebuilt from scratch with proper rate-based pricing. Groups become first-class billable entities. Services and crew unified into one cohesive workflow.

## Vision

### 10x Check
The 10x version transforms the project from a record-keeping tool into a real-time command center for events. Live equipment tracking during load-in, drag-and-drop quote builder that feels like Notion, crew seeing their assignments in a mobile-optimized view, financial health dashboard showing profit margin in real-time as items are added/removed.

### Platonic Ideal
The user opens a project and immediately sees: status, timeline, PMs, financial health (revenue vs cost), equipment status by category. They click into "RF" category, see their groups ("Wireless Microphone Package", "IEM System"), expand a group to see tracked assets. They write a description, set a price (with a suggestion glowing subtly), and hit "Generate Quote." The quote is perfect. Adding crew feels like scheduling — drag a person onto a day, assign them to a service. The whole thing feels like one cohesive surface, not tabs-of-separate-features.

## Architecture

### New Data Model

```
PROJECT
  + defaultRentalPeriod (DAILY | WEEKLY)
  + defaultRentalQuantity (Int)
  + taxRate (Decimal, nullable → inherits from org)
  + serviceCostTotal, labourCostTotal, equipmentRevenue, margin
  - projectManagerId (REMOVED → join table)

ProjectManager (new join table)
  projectId, userId, addedAt

ProjectCategory (new)
  id, projectId, name, sortOrder

ProjectGroup (new — the billable unit)
  id, categoryId, title, description, quantity, price,
  suggestedPrice, rentalPeriod, rentalQuantity, sortOrder

ProjectLineItem (modified)
  + categoryId (nullable FK → ProjectCategory)
  + groupId (nullable FK → ProjectGroup)
  - groupName (REMOVED — replaced by groupId)

Model (modified)
  + dailyRate   Decimal?
  + weeklyRate  Decimal?

Organization (modified)
  + defaultTaxRate  Decimal?  (default 10.00)

ProjectService (modified)
  - lineItemId (REMOVED — no more shadow line items)
  + costTotal (direct roll-up)

GroupTemplate (new — reusable group configurations)
  id, organizationId, name, description,
  items: GroupTemplateItem[] (modelId, quantity)
  createdAt, updatedAt

GroupTemplateItem (new)
  id, templateId, modelId, quantity
```

### Financial Calculation

```
equipmentRevenue = SUM(group.price × group.quantity) + SUM(standalone.lineTotal)
serviceCostTotal = SUM(service.costTotal)
labourCostTotal = SUM(assignment.estimatedCost)

subtotal = equipmentRevenue
discountAmount = subtotal × discountPercent / 100
taxableAmount = subtotal - discountAmount
taxRate = project.taxRate ?? org.defaultTaxRate ?? 10
taxAmount = taxableAmount × taxRate / 100
total = taxableAmount + taxAmount

margin = total - (serviceCostTotal + labourCostTotal)
marginPercent = margin / total × 100
```

### Project Hierarchy

```
Project
  → ProjectCategory (top-level organiser: "RF", "IEM", "PA")
      → ProjectGroup (billable unit: title, description, qty, price)
          → ProjectLineItem (equipment tracking only, not on quote)
      → ProjectLineItem (standalone, appears as its own line item)
  → ProjectLineItem (uncategorized)
  → ProjectService (direct cost roll-up, no shadow line items)
  → CrewAssignment (direct cost roll-up)
  → ProjectManager (multi-PM via join table)
```

## Key Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Approach | Full architectural rewrite | Architectural coherence over incremental |
| Migration | Clean migration (groupName → ProjectGroup) | One codepath going forward |
| Services+Crew UX | Single "Labour & Logistics" tab | One tab, one mental model |
| Rental period | Project-level default + per-group/line override | Less clicking for common case |
| Shadow line items | Removed entirely | Services have direct cost roll-up |
| Group ↔ Line Item | Direct FK (groupId on ProjectLineItem) | Simpler than join table, 1:1 relationship |
| Delete group/category | Cascade to ungrouped | Assets stay on project, nothing lost |

## Accepted Scope Expansions

1. **Smart price suggestion** — one-click accept on group pricing
2. **Financial health summary** — revenue/cost breakdown + margin indicator
3. **Drag assets between groups/categories** — fluid organization via @dnd-kit
4. **Project duplication preserves structure** — categories/groups/items maintained
5. **Inline category creation** — ComboboxPicker creatable
6. **Crew cost vs equipment revenue split** — in financial summary
7. **Configurable tax rate** — org default + per-project override
8. **Financial audit trail** — "How this was calculated" collapsible breakdown
9. **Group templates / Quick-add** — save group configurations as reusable templates, one-click apply when creating new groups

## NOT in Scope

## Future-Proofing

### ROI Tracking (future)
Models track purchase cost. For groups, asset purchase costs calculate percentage splits, then the group's project price splits proportionally to each asset's ROI. Data model supports this via Model.dailyRate/weeklyRate + Asset.purchasePrice.

### Xero Integration (future)
Projects push to Xero with groups as line items + ungrouped standalone assets as separate line items. Data model supports this via ProjectGroup.title/description/quantity/price.

### Drag & Drop Spec

```
VISUAL FEEDBACK:
  Drag handle: 6-dot grip icon (fg-4), left edge of group card
  Picking up: Source item scales to 0.97, opacity 0.5
  Dragging: Item follows cursor with spring physics
  Valid drop target: 2px teal-200 dashed border on target zone
  Invalid drop: 2px red-subtle border + micro shake, snap back
  Drop confirmed: Spring settle animation + toast "Moved to {group}"
  Both groups recalculate suggestions on drop

TOUCH DEVICES (< md viewport):
  Drag handles hidden
  Each item gets "⋯" menu → "Move to group..." / "Move to category..."
  Opens picker popover with list of groups/categories
  Same server action, touch-native pattern

KEYBOARD A11Y:
  Space to pick up, arrows to navigate, Space to drop
  @dnd-kit announcements for screen readers
  aria-roledescription="sortable" on drag handles
```
