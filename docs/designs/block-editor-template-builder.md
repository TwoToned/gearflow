# CEO Plan: Block Editor Template Builder
Generated by /plan-ceo-review on 2026-03-19
Branch: claude/admiring-khorana | Mode: SCOPE EXPANSION
Repo: TwoToned/gearflow

## Vision

### 10x Check
A visual document composer where you feel like you're directly manipulating the PDF. Canva's document editor meets Notion's block flexibility, purpose-built for rental industry documents. Drag blocks around a canvas, see PDF update in real-time, create any layout from simple quotes to complex multi-section return sheets with bank details, signatures, and custom branding.

### Platonic Ideal
The editor feels inevitable — you open it and just know how it works. Click "+" between rows, section picker appears. Drag a section next to another, they snap into columns. Hover column divider, drag to resize. Preview updates live. Save layouts as presets. A new employee builds a professional invoice template in under 2 minutes without documentation.

## Architecture

### Data Model: TemplateBlock
```typescript
interface TemplateBlock {
  id: string;
  type: 'row' | 'column' | SectionType;
  children?: TemplateBlock[];    // rows have columns, columns have content
  settings?: SectionSettings;    // content blocks only
  visibility?: SectionVisibility;
  content?: string;
  columnWidths?: number[];       // row only: [50, 50] or [30, 70]
  styling?: BlockStyling;        // bg color, border, padding, margin
}

interface BlockStyling {
  backgroundColor?: string;      // hex color
  borderColor?: string;          // hex color
  borderWidth?: number;          // pt
  padding?: number;              // mm
  margin?: number;               // mm
}
```

### Layout Rules
- **2 levels deep:** rows -> columns -> content blocks (no deeper nesting)
- **Max 4 columns** per row
- **Page breaks between rows** (never mid-row, except table overflow)
- **Row height = max(column heights)** - shorter columns get bottom whitespace
- **Column width enforcement:** minimum widths per section type

### Section Type Minimum Widths
| Type | Min Width | Reason |
|------|-----------|--------|
| table | 100% | Equipment columns need full width |
| crew-table | 100% | Multi-column crew data |
| page-break | 100% | Structural element |
| totals | 50% | Number columns need space |
| header | 50% | Logo + text |
| signature | 33% | One signature per column works |
| client-details | 33% | Key-value pairs |
| project-details | 33% | Key-value pairs |
| custom-text | 25% | Text reflows naturally |
| notes | 25% | Text reflows naturally |
| spacer | 25% | Just whitespace |

### Migration
Existing `TemplateSection[]` auto-wrapped on read:
```
Each section -> { type: 'row', children: [
  { type: 'column', children: [
    { type: original_type, settings, visibility, content }
  ]}
]}
```
No database migration needed — blocks stored as JSON in existing `sections` column.

## Scope Decisions

| # | Proposal | Effort | Decision | Reasoning |
|---|----------|--------|----------|-----------|
| 1 | Flexible column widths (30/70, 25/50/25, etc) | M | ACCEPTED | Power users need precise control |
| 2 | Drag-to-create columns (drag section next to another) | L | ACCEPTED | Core Notion-like interaction |
| 3 | Insert-anywhere with '+' buttons between rows | S | ACCEPTED | Essential for non-linear editing |
| 4 | Per-section background colors and borders | M | ACCEPTED | Visual differentiation in PDFs |
| 5 | Section padding and spacing controls | S | ACCEPTED | Fine-grained layout control |
| 6 | Section color coding in editor (left-edge bars) | S | ACCEPTED | Visual scanning aid, zero PDF impact |
| 7 | Template gallery with auto-generated thumbnails | M | ACCEPTED | Visual template selection |
| 8 | Full keyboard shortcuts (arrows, Enter, Delete, Cmd+D) | S | ACCEPTED | Power user speed |
| 9 | Slash command section insertion | M | SKIPPED | Section library dialog is sufficient |
| 10 | Copy/paste sections across templates (Cmd+C/V) | M | ACCEPTED | Cross-template reuse beyond presets |
| 11 | Multi-page pagination engine rebuild | L | ACCEPTED | Current pagination is fundamentally broken — 14 bugs found (5 critical) |

## Accepted Scope
- Block editor data model (rows -> columns -> content blocks, 2 levels deep)
- Flexible column widths with presets and custom ratios
- Drag-to-create columns (drag section to edge of another)
- Insert-anywhere '+' buttons between rows
- Per-section background colors and borders in PDF
- Section padding and spacing controls
- Section color coding in editor sidebar
- Template gallery with auto-generated thumbnails
- Full keyboard navigation shortcuts
- Copy/paste sections across templates
- Migration for existing flat-list templates to block model
- **Multi-page pagination engine rebuild** — proper layout engine that measures actual content heights, clips content to page boundaries, handles overflow for all section types (not just tables), and tracks Y positions correctly across continuation pages

## Not in Scope
- Slash command insertion — section library dialog is sufficient
- Recursive nesting deeper than 2 levels — PDF columns would be unreadably narrow
- WYSIWYG click-to-edit on the PDF preview — requires rendering HTML to match PDF exactly
- Custom section type plugins — users define from existing types

### Multi-Page Pagination Engine
The current pagination system has 14 identified bugs (5 critical). The block-aware renderer will include a proper layout engine:

**Critical bugs to fix:**
1. Table split math doesn't account for document header on continuation pages
2. Non-table sections (crew table, signature, totals, custom text) have zero overflow handling
3. Y-position tracking broken after table splits
4. Nested kit items bypass overflow checks in table plugin
5. No actual content clipping — partially-drawn rows aren't clipped to page boundary

**New layout engine requirements:**
- Measure actual content heights (not estimates) before placing on page
- Row-level page breaks: rows are atomic units, page break between rows only
- Table overflow: split table rows across pages with repeated headers
- Crew table overflow: same split logic as equipment tables
- All sections must overflow-check (signature, totals, custom text, notes)
- Correct Y-position tracking across continuation pages with document header offset
- Content clipping at page boundaries for any partial overflow
- Block styling (backgrounds, borders) must re-draw on continuation pages

### Block Tree Visual Language
- Sections use **flat list with border-b dividers** (NOT cards — per DESIGN.md anti-pattern)
- Selected section: **left-edge 2px teal bar** + `teal-subtle` background
- All section types use **teal left-edge bars** + type-specific icons for differentiation (NOT multiple colors — per DESIGN.md "teal as sole accent")
- Drag handle: 6-dot grip icon, `fg-4` color
- Multi-column rows shown as grouped blocks with width labels (e.g., "60% | 40%")

### '+' Insert Buttons
- **Invisible by default** — just a thin `border-b` line between rows
- **On hover:** line extends with centered '+' icon (12px, teal, `bg-surface` circle breaking the line)
- **On click:** opens section library dialog positioned at that insertion point
- Notion-like: subtle until needed

### Column Width Controls
- **Preset buttons:** visual rectangles showing splits (50|50, 60|40, 70|30, 25|50|25) in row settings
- **Drag handle:** draggable divider between columns in block tree. Live percentage labels during drag. Snaps to common ratios (25%, 33%, 50%, 66%, 75%)
- Both available — presets for quick selection, drag for fine-tuning

### Drag-to-Create Columns
- When dragging a section near the left/right edge of another section:
  - **Teal dashed border** appears on the target edge
  - **Ghost column preview** shows the split (target section shrinks to show new column position)
- On drop: wraps both sections in a row with 50/50 default split

### Preview
- **Center pane:** HTML approximation that updates instantly on edit. Shows section ordering, column layouts, approximate sizing. Not pixel-perfect but fast.
- **"Preview PDF" button:** generates real PDF, shows in fullscreen modal. Accurate but 600ms+ render time.
- **Page navigation:** "Page 1 of 3" with prev/next arrows (in PDF modal)

### Template Gallery (Settings > Document Templates)
- **List view** (NOT card grid) — each template as a table row with:
  - Small thumbnail (48x64px) on left
  - Template name, doc type, version in middle
  - Dot + text status indicator ("Published" / "Draft")
  - Left-edge teal bar for the org default template
  - Quick actions (Edit, Duplicate, Delete) on hover
- Uses existing RVLT Flow table row hover pattern

### Template Creation Dialog
On "+ New Template":
1. **Pick doc type** (Quote, Invoice, Packing List, Return Sheet, Delivery Docket)
2. **Starting point:**
   - "Start from defaults" — pre-loaded sections for that doc type
   - "Start from scratch" — blank canvas with onboarding prompt
   - "Start from preset" — if saved presets exist

### Empty States
- **Empty editor (blank canvas):** documents spot illustration (44px teal container) + "Start building your template" (14px/700) + "Add sections to create your document layout" (11px, fg-3) + [+ Add First Section] primary button
- **Empty template gallery:** "No templates yet" + "Create your first document template to customize your quotes, invoices, and more" + [+ Create Template] button
- **Empty presets tab:** "No saved presets yet" + "Save your current sections to reuse them across templates"

### Interaction States
| Feature | Loading | Empty | Error | Success |
|---------|---------|-------|-------|---------|
| Editor load | Skeleton tree + preview placeholder | Onboarding prompt + [+ Add First Section] | "Failed to load" + retry | Tree + preview populated |
| HTML preview | Shimmer overlay | "Add sections to see preview" | "Preview unavailable" | Rendered HTML layout |
| PDF preview modal | "Generating PDF..." spinner | N/A | "PDF generation failed" + details | PDF viewer in modal |
| Save | Button spinner + disabled | N/A | Toast: "Save failed" | Toast: "Template saved" |
| Publish | Button spinner | N/A | Toast: "Publish failed" | Toast: "Published" + status badge |
| Section library | Presets tab spinner | "No presets yet" | Toast: "Failed to load" | Section added, dialog closes |
| Template gallery | Skeleton rows | Empty state w/ CTA | "Failed to load" | List of template rows |
| Copy/paste | Instant | Paste w/ nothing: no-op | Toast: "Invalid clipboard" | Toast: "Section pasted" |

### Accessibility
- Block tree: `role="tree"` with `role="treeitem"` per section
- Settings panel: `role="complementary"` with `aria-label="Section settings"`
- '+' buttons: `aria-label="Insert section after [name]"`
- Focus management: after drag → moved section, after delete → next section, after insert → new section
- All text meets WCAG AA contrast (4.5:1 normal, 3:1 large)
- Touch targets: 44px minimum (buttons, drag handles)

### Responsive
- **Desktop (1024px+):** Full three-pane editor
- **Below 1024px:** "Please use a desktop browser to edit templates" message
- **Template gallery:** responsive on all viewports (it's just a list/table)

### Motion & Animation
| Interaction | Animation | Duration |
|-------------|-----------|----------|
| Section reorder (drag) | Smooth position swap, other items shift | 200ms, ease-out |
| Column creation (drop on edge) | Ghost preview → solid layout | 300ms, spring |
| '+' button appear | Opacity 0→1 + scale 0.8→1 | 150ms, ease |
| Settings panel open | Slide from right | 200ms, ease-out |
| Preview update | Crossfade | 150ms, ease |
| Section delete | Collapse height + fade | 200ms, ease |
| All above | Respect `prefers-reduced-motion` → instant/opacity only | — |
